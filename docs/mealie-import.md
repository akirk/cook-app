# Import recipes from Mealie

In Cook App Settings, use **Import recipes or restore a Cook App backup** to select a Mealie recipe-export ZIP. Both single-recipe ZIPs and bulk recipe exports are supported. Use Mealie's recipe export, not its administrator/database backup.

Import creates new recipes under the signed-in user, reuses existing taxonomy terms by name, and adds bundled photos to the WordPress media library. Repeating the import creates additional copies. Unit preferences and household ingredients are unchanged. Importing photos requires permission to upload files.

## Data mapping

| Mealie data | Cook App result |
| --- | --- |
| Name and description | Recipe title and description. |
| Serving count | Recipe servings, converted to a positive integer; the app uses whole servings. |
| Preparation / cooking times | Minutes. ISO 8601 durations, numeric minutes, `HH:MM:SS`, and English day/hour/minute strings are supported. Cooking time falls back to total minus preparation. Other time text currently results in zero minutes. |
| Structured ingredient quantity, food, unit, note | Amount, name, unit, and ingredient notes; decimals are retained without parsing display text. Unit abbreviations are used when present, otherwise unit names. |
| Ingredients with only display/note text | Parsed using Cook App's existing ingredient-line parser. |
| Ingredient and instruction section titles | Recipe parts, matched by title and occurrence. |
| Instruction summary and text | Instruction text, with the summary prefixed when present. |
| Recipe notes | Notes with their titles and text. |
| Categories and tags | Recipe category and tag taxonomies. |
| `org_url` / `orgURL` | Original source URL. |
| Bundled `original.webp` | A new media attachment and featured image for that recipe. |

Nutrition, ratings, comments, additional assets/images, Mealie access settings, ingredient substitutions, and links to other Mealie recipes are not transferred as application features. A referenced recipe ingredient can retain its display text but is not linked to another imported recipe. Lists, plans, history, and user settings are outside the recipe-export import. New recipes follow Cook App's normal published recipe behavior rather than copying Mealie's access settings.

## Archive layouts and limits

The supported layouts match Mealie v3.28.0:

```text
# Single recipe export
<slug>.json
original.webp                 # optional

# Bulk recipe export
recipes/<slug>/<slug>.json
recipes/<slug>/images/original.webp   # optional, per recipe
```

Both snake_case and camelCase recipe field names are recognized. Paths are read directly from the ZIP; the archive is never extracted. Absolute paths, traversal paths, symlinks, duplicate paths/recipe IDs, and corrupt entries are rejected. All recipe records and original photos are validated before creating content.

The uploaded archive and the sum of its expanded entries must each fit within 10,485,760 bytes (10 MiB), with at most 2,000 entries. Unused assets count toward those limits. The normalized restore payload must also fit the backup validator's 10 MiB limit. Photos must be valid WebP images with at most 40 million pixels, and WordPress must permit WebP uploads. The PHP ZIP extension is required.

If content or photo restoration fails, newly created posts, taxonomy terms, and attachments are removed. Temporary image files are cleaned up on success and failure.

## Verification

The fixtures are synthetic recipe data modeled on Mealie v3.28.0's native fields. ZIP tests construct archives at runtime, checking both layouts, quantities, sections, separate per-recipe photos, invalid input, path and size limits. Isolated WordPress tests check actual restore mapping, photo attachment, permission checks, and rollback after a later photo failure.

Single and bulk ZIPs generated by the following Mealie v3.28.0 exporter implementations were also decoded successfully, with their database/model dependencies stubbed. This is format-level verification; migration through a running Mealie server has not been tested.

- [Single-recipe ZIP exporter](https://github.com/mealie-recipes/mealie/blob/v3.28.0/mealie/services/recipe/template_service.py).
- [Bulk recipe exporter](https://github.com/mealie-recipes/mealie/blob/v3.28.0/mealie/services/exporter/recipe_exporter.py) and [JSON/archive writer](https://github.com/mealie-recipes/mealie/blob/v3.28.0/mealie/services/exporter/_abc_exporter.py).
- [Recipe fields](https://github.com/mealie-recipes/mealie/blob/v3.28.0/mealie/schema/recipe/recipe.py) and [ingredient fields](https://github.com/mealie-recipes/mealie/blob/v3.28.0/mealie/schema/recipe/recipe_ingredient.py).

vendor/bin/phpunit --filter Mealie
